# Инсталиране на VEDAR

## Изисквания

| | Минимум | Препоръчително |
|---|---|---|
| Операционна система | Windows 10 x64, версия 1809 или по-нова | Windows 11 x64 |
| Процесор | 4 логически ядра, x64 | 8 ядра |
| Памет (RAM) | 4 GB | 8 GB (16 GB за локален Ollama) |
| Свободно място | 700 MB | 2 GB (за по-големи модели) |
| Микрофон | Вграден или външен | Слушалки с микрофон |
| Звук | Тонколони или слушалки | Слушалки (по-добро разпознаване) |
| Интернет | Не е нужен за основните функции | Нужен за разговори с BgGPT |

Не е нужно да инсталирате .NET, Visual Studio, Python или друг софтуер. Всичко необходимо е в
инсталатора (включително речевите модели и Microsoft Visual C++ Runtime).

## Инсталиране стъпка по стъпка (с екранен четец)

1. Стартирайте файла **VEDAR-Setup-v0.1.0-x64.exe** (Enter върху него във File Explorer).
2. Ако Windows покаже „Windows защити компютъра ви“ (SmartScreen): инсталаторът още не е цифрово
   подписан. Натиснете **Tab** до връзката „Повече информация“, **Enter**, после **Tab** до бутона
   „Стартиране въпреки това“ и **Enter**. Ако инсталаторът е изтеглен от неизвестен източник, проверете
   контролната му сума (вижте по-долу).
3. Ако се появи въпрос „За кого да бъде инсталирано“, изберете **„Само за мен“** (препоръчително — не
   изисква администраторски права). „За всички потребители“ изисква администратор.
4. Прозорците на инсталатора са на български. Прочетете информацията, натиснете **Напред** (Enter).
5. На страницата „Допълнителни задачи“ (отметките се превключват с **Интервал**):
   * „Стартирай VEDAR автоматично при влизане в Windows“ — препоръчително, включено по подразбиране;
   * „Икона на работния плот“ — по желание.
6. Натиснете **Инсталирай**. Инсталацията отнема около минута; накрая инсталаторът проверява
   контролните суми на речевите модели.
7. На последната страница оставете отметката „Стартирай VEDAR сега“ и натиснете **Край**.
8. При първото стартиране Ведар ви превежда през **настройката с глас** — без писане (вижте по-долу).

Ведар се инсталира в `%LOCALAPPDATA%\Programs\VEDAR` (само за вас) или в `C:\Program Files\VEDAR`
(за всички потребители). Създава се пряк път **VEDAR** в менюто „Старт“ с бърз клавиш **Ctrl + Alt + V**.

## Първоначална настройка

**С глас (по подразбиране).** Ведар пита и вие отговаряте след сигнала: име → скорост на гласа → как да
извиквате и спирате Ведар → автоматично стартиране → ключ за BgGPT → ключ за Groq (резервен, безплатен).
Ключовете не се диктуват: копирайте ключа (например от имейла с Ctrl + C) и кажете „готово“. Всеки въпрос
може да се пропусне с „пропусни“. Подробности: USER_GUIDE_BG.md, раздел 0.

**С клавиатура** (ако няма микрофон или речевите модели липсват): стъпките са приветствие → вашето име →
проверка на микрофона → тест на гласа → проверка на речевите модели → ключ за BgGPT (може да се
пропусне) → проверка на връзката (може да се пропусне) → автоматично стартиране → обяснение на командите
→ готово.

Навигация: **Tab** между елементите, **Enter** за избор. Бутони: **Напред** (Alt + Н), **Назад**
(Alt + А), **Пропусни** (Alt + С), **Готово** (Alt + Т на последната стъпка). При всяка нова стъпка
фокусът отива на текста ѝ, за да го прочете екранният четец. Ако няма екранен четец, Ведар прочита
стъпката сам.

Без ключ за BgGPT всички местни команди работят. Ключът може да се въведе по-късно.

## Тиха инсталация (за дневни центрове и администратори)

```bat
VEDAR-Setup-v0.1.0-x64.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /CURRENTUSER /TASKS=autostart
```

* `/ALLUSERS` вместо `/CURRENTUSER` — за всички потребители (изисква администратор). При инсталация за
  всички потребители автоматичното стартиране се включва от всеки потребител в настройките на Ведар.
* `/TASKS=autostart,desktopicon` — и икона на работния плот.
* `/LOG=C:\vedar-setup.log` — дневник на инсталацията.
* `/DIR="D:\VEDAR"` — друга папка.

Първоначалната настройка се показва при първото стартиране за всеки потребител.

## Обновяване

Стартирайте инсталатора на новата версия. Той затваря работещия Ведар (`VEDAR.exe --exit`), заменя
файловете и **запазва** всички настройки, ключа и историята — те се пазят отделно в
`%LOCALAPPDATA%\VEDAR`.

## Деинсталиране

* **Настройки на Windows → Приложения → Инсталирани приложения → VEDAR → Деинсталиране**, или
* „Контролен панел → Програми и компоненти“, или
* `%LOCALAPPDATA%\Programs\VEDAR\unins000.exe`.

Деинсталаторът премахва програмата, преките пътища и автоматичното стартиране. След това **пита** дали да
изтрие и личните данни (настройки, ключ, история, дневници). По подразбиране отговорът е „Не“. При тиха
деинсталация (`/VERYSILENT`) личните данни се запазват.

## Къде се пазят данните

| Какво | Къде |
|---|---|
| Програмата | `%LOCALAPPDATA%\Programs\VEDAR` |
| Настройки | `%LOCALAPPDATA%\VEDAR\settings.json` |
| Ключ за BgGPT (шифрован с Windows DPAPI) | `%LOCALAPPDATA%\VEDAR\secrets\` |
| История (само ако е включена; шифрована) | `%LOCALAPPDATA%\VEDAR\history\` |
| Дневници (7 дни, без ключове и без разпознат текст по подразбиране) | `%LOCALAPPDATA%\VEDAR\logs\` |
| Допълнително изтеглени модели | `%LOCALAPPDATA%\VEDAR\models\` |
| Автоматично стартиране | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` → `VEDAR` |

## Проверка на целостта на инсталатора

До инсталатора има файл `VEDAR-Setup-v0.1.0-x64.exe.sha256` (в изданието `latest-build` в GitHub
Releases двата файла са един до друг). Проверка в PowerShell:

```powershell
Get-FileHash .\VEDAR-Setup-v0.1.0-x64.exe -Algorithm SHA256
```

Резултатът трябва да съвпада със стойността във файла `.sha256`.

## По-големи модели за разпознаване

Инсталаторът включва модела **Whisper small** (190 MB), подходящ за обикновен компютър. В Настройки →
Микрофон → „Модел за разпознаване на реч“ можете да изтеглите по-точни модели (Medium — 540 MB, Large v3
Turbo — 575 MB). Всеки изтеглен модел се проверява със SHA-256 преди да бъде използван.

## Отстраняване на проблеми

* **Ведар не стартира:** вижте дневника в `%LOCALAPPDATA%\VEDAR\logs`. Опитайте „Изтрий всички мои
  данни“ или изтрийте `settings.json` (Ведар създава нов с настройки по подразбиране).
* **Няма звук от Ведар:** проверете изходното устройство в Настройки → Глас.
* **Микрофонът не се открива:** Настройки на Windows → Поверителност и защита → Микрофон → разрешете
  достъп до микрофона за настолни приложения.
